Keyboard Shortcuts
Map Size
Tiles keep their positions. Anything outside the new size is removed, and Undo brings it back.
Tile Size
Match the tileset image: 16, 32, 48 and 64 are the usual sizes. Placed tiles stay on their grid cells.
Change Tileset
Tiles already on the map keep their tile numbers, so a tileset laid out differently will change how the map looks.
Rename Layer
Leave it empty to go back to the plain layer number.
Quick Tips

Drawing

  • Pick a tile on the right, then left-click or drag on the map to place it
  • Drag across several palette tiles to pick a block; the pencil stamps the whole block, and the fill tools repeat it as a pattern
  • Right-click erases, whatever tool is selected
  • Fill covers a connected empty area, or replaces a connected run of the same tile
  • Fill Erase removes a connected run of the same tile
  • Row Fill and Column Fill paint a whole line in one click

Layers

  • Layer 1 is the background; higher layers draw on top
  • Press 1 to 9 or use the Layer menu to switch, and add up to 10 layers
  • Other layers are faded so you can see what you are drawing over. Turn that off in View
  • The eye in the Layer menu hides a layer; H hides or shows the current one. Layers can be renamed

Tileset

  • File, then Change Tileset: paste an image URL or choose an image
  • Use the + and - buttons above the palette to zoom the tiles
  • Set the tile size (Edit, then Tile Size) to match the image before drawing
  • Swapping to a tileset with a different layout changes what placed tiles look like

Moving Around

  • Mouse wheel zooms toward the pointer, from 25% to 400%
  • Hold Space and drag, or drag with the middle mouse button, to pan
  • Press 0 to go back to 100%

Saving

  • Ctrl+S saves your project
  • Export PNG makes an image of the layers you choose, with transparency
